A little context for your numbers

Lines & change

Growth is added minus removed. Churn is added plus removed. Binary-file line changes are excluded. Renames use a 50% similarity threshold.

History & scope

Only non-merge commits are analyzed, using committer dates. Start is inclusive; end is exclusive. Filters intersect, including an applied commit selection.

Activity metrics

Modifications count commits with nonzero churn (each commit once per scope). Frequency = modifications ÷ selected commits, from 0 to 1. Churn rate = changed lines ÷ selected commits.

Author ownership

Ownership = author churn ÷ all-author churn, displayed as a percentage. Its denominator includes the entire commit set at the selected scope, even when one author is selected. Merged aliases share a canonical identity.
